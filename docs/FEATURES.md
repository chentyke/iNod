# 官网与 App 功能对照

下表列出 NodeSeek 官网功能在 iNod 中的入口。原生页面使用 SwiftUI，需要验证码或第三方授权的环节沿用官网流程。

| 官网功能 | App 入口与实现 |
| --- | --- |
| 首页、分类、排序与分页 | 社区，版块列表从官网更新 |
| 推荐阅读 | 社区工具 |
| 帖子、用户、Google 搜索 | 社区搜索和社区工具 |
| 阅读与回复 | 原生正文、评论、引用、列表、表格、代码、表情和图片放大 |
| 发帖、编辑主题、编辑回复 | 社区右上角 +，或帖子与评论菜单 |
| 引用回复与表情插入 | 评论菜单、原生编辑器 |
| 点赞、鸡腿、反对 | 正文和评论下方，显示已有状态与免费额度 |
| 站内收藏 | 「我的」中的收藏、帖子书签、列表左滑和长按菜单，使用 NodeSeek 账号保存 |
| 楼主置顶回复 | 评论菜单，置顶前确认 5 鸡腿费用 |
| 显示被屏蔽的内容 | 账号设置，默认隐藏，开关保存在本机 |
| 用户主页、主题与回复 | 作者头像或名称 |
| 关注、粉丝 | 「我的」和个人主页 |
| 私聊 | 通知、用户主页，支持全部标为已读 |
| 回复、@我通知和未读数 | 通知页和底栏数字提示，支持前台刷新 |
| 鸡腿 / 星尘明细 | 「我的」，星尘支持按类型、对方 UID 和 Ref ID 筛选 |
| 星尘转账和收款按钮 | 星尘页、他人主页、编辑器 |
| 签到、等级与今日进度 | 「我的」 |
| 邀请码管理和购买 | 「我的」、社区工具 |
| 抽奖创建、分享、开奖 | 社区工具、开奖链接 |
| 投票创建、参与、公开参与者、结束 | 编辑器和帖子组件 |
| 管理记录和单条记录 | 社区工具，只读 |
| 个人介绍、签名、首页版块、屏蔽名单 | 账号设置 |
| 头像、密码、双因素验证 | 账号设置 |
| 官网节日装饰、自定义 CSS | 账号设置 → 官网显示设置，CSS 按官网权限显示 |
| 邮箱 / 手机验证、Telegram 授权、密码找回 | 登录与安全，Telegram 状态和解绑为原生页面 |
| 登录、注册、验证码 | 原生登录表单与双因素验证码，内嵌官网人机验证，注册沿用官网 |
| 图片上传与管理 | 编辑器图片菜单、账号设置，NodeImage 密钥保存在 Keychain |
| 合作商家、友情链接 | 社区工具 |
| 商家规则、Premium Provider、广告合作 | 社区工具，打开对应主题的原生阅读页 |
| 关于、隐私、RSS、电报频道 | 社区工具 |

## 仍使用官网的部分

复杂 HTML、外站嵌入和特殊互动排版使用阅读页「在官网查看」。邮箱 / 手机验证码和 Telegram 登录授权使用官网，避免重做网站的验证机制。这些官网页面都在系统浏览器中打开；只有官网要求人机验证时，App 内打开官网完成验证，因为只有这样验证结果才会同步给 App。网站自定义 CSS 不作用于 App 原生界面。

没有给普通账号增加管理员控制台、删除投票或重新开启已结束投票等管理操作。没有实现网站未提供的 iOS 系统推送、私信附件上传、消息编辑或删除。

本机测试步骤见 [CI 维护指南](CI.md)。
